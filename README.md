# Anagram Board

A tiny, dependency-free manual anagram workspace.

Type any word, sentence, phrase, or name and turn it into movable letter tiles. The tool does not solve anagrams automatically; it is designed to make experimenting with them visually easier.

## Features

- Freeform tile dragging
- Tiles stay exactly where you drop them
- Shuffle, reset, reverse, and clear controls
- Optional spaces, punctuation, and case preservation
- Touch and mouse support
- No dependencies or build step

Open `index.html` directly in a browser, or publish the repository with GitHub Pages.
